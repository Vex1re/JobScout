# 🎯 JobScout Bot — Высоконагруженный универсальный агрегатор вакансий и фриланса

> **JobScout Bot** — это production-ready асинхронный Telegram-бот на базе **Aiogram 3**, **SQLAlchemy 2 Async**, **PostgreSQL 16**, **PgBouncer**, **Redis 7** и распределённой очереди задач **arq**. Предназначен для специалистов **всех отраслей и профессий** (IT, маркетинг, дизайн, продажи, бухгалтерия, юриспруденция, HR, логистика и менеджмент). Агрегирует предложения с 9+ платформ, отсекает скам и токсичные условия (red flags), выполняет двухфакторную дедупликацию (SimHash), предоставляет карьерный трекер откликов и монетизацию через **Telegram Stars**.

## 🌟 Ключевые возможности

### 1. Многоканальный сбор данных (9+ источников)
- 💼 **HeadHunter (hh.ru)**: официальное REST API с поиском по навыкам, удалёнке и многостраничной выгрузкой.
- 🚀 **Хабр Карьера (career.habr.com)**: профильные IT-вакансии для разработчиков и инженеров.
- 🇷🇺 **Работа России / ТрудВсем (trudvsem.ru)**: открытое REST API госслужбы (25 000+ предложений) со встроенным **Circuit Breaker** и защитой от сбоев 500.
- 👔 **SuperJob (superjob.ru)**: корпоративные вакансии для любых специальностей (REST API + веб-поиск).
- 🌍 **RemoteOK (remoteok.com)**: открытое REST API мировой 100% удалёнки с оплатой в USD.
- ⚡ **Kwork (kwork.ru)**: маркетплейс микро-услуг и разовых задач (дизайн, тексты, разработка, маркетинг).
- 💻 **FL.ru (fl.ru)**: крупнейшая биржа фриланса Рунета (парсер актуальных заказов).
- 🌐 **Хабр Фриланс / Freelance.ru**: проектные заказы и задачи.
- 🏢 **Работа.ру (rabota.ru)**: универсальная база вакансий экосистемы Сбера.
- 🤝 **Freelancehunt (freelancehunt.com)**: API v2 за feature-флагом.

### 2. Разделение Ingestion и Search + Дедупликация
- **Crawler-воркеры**: собирают данные по фиксированным «корзинам» (роль × город × remote) в фоновом режиме.
- **Двухуровневая дедупликация**:
  - `canonical_id` (MD5 нормализованных компании, названия, города и вилки зарплаты).
  - **SimHash (64-битный отпечаток)** описания вакансий (Hamming distance $\le 3$) — схлопывает кросс-источниковые дубликаты.
- **Защита внешних источников**: `TokenBucket` rate limiter и `CircuitBreaker`.

### 3. Гибридный парсинг резюме (Regex + LLM Fallback)
- Поддержка форматов: **PDF**, **DOCX**, **TXT** и прямой ввод текста.
- **Rule-based парсер**: мгновенный локальный расчёт стажа через алгоритм объединения интервалов (Interval Union), нормализация навыков (каталог 250+ синонимов и 192 канонических скилла).
- **LLM Fallback**: подключается **только** с согласия пользователя (`llm_consent=True`) при низкой уверенности (`confidence < 0.6`). Входные данные очищаются от Prompt Injection и PII (телефоны, почты).

### 4. Продвинутый матчинг и ранжирование
- **Конфигурируемые веса**: 45% стек технологий, 25% целевая роль, 30% грейд и опыт.
- **Soft Penalty по грейду**: штраф 12% при низкой уверенности грейда вместо дисквалификации.
- **Freshness Time Decay**: учёт свежести публикации (плавное снижение скора для вакансий старше 14 и 30 дней).
- **Каталог 165 городов РФ** (`data/cities.json`) с учётом региональных центров и синонимов.

### 5. Трекер откликов (Kanban) и AI-сопроводительные
- Команда `/tracker`: ведение статусов откликов прямо в Telegram (`Сохранено` ➔ `Откликнулся` ➔ `Интервью` ➔ `Оффер` / `Отказ`).
- Генерация персонализированных **AI Cover Letters** под требования конкретной вакансии.
- **AI Gap Analysis**: детальный разбор недостающих навыков соискателя перед откликом.

### 6. Монетизация и Telegram Stars
- Команда `/premium`: оформление подписок за **Telegram Stars (XTR)** (тарифы Pro и Team).
- Архитектура **Entitlements**: права доступа развязаны со шлюзом оплаты.
- Поддержка альтернативных шлюзов (`YooKassaProvider`, `CryptoBotProvider`) под feature-флагами.

### 7. Observability, Мониторинг и Sentry
- Эндпоинт `/healthz`: Liveness & Readiness проверка базы данных и Redis.
- Эндпоинт `/metrics`: Стандартные метрики Prometheus для сбора скрейперами.
- **Sentry**: автоматическая маскировка персональных данных (PII Redaction) для телефонов РФ, email и токенов ботов.
- **Canary Monitor**: скрипт `scripts/canary.py` для тестирования жизнеспособности парсеров.
- **Golden Evaluation**: скрипт `scripts/eval_matcher.py` для проверки точности ранжирования.

## 🛠️ Переменные окружения (`.env`)

Все параметры типизированы через Pydantic-Settings в `core/config.py`:

| Переменная | Обязательность | Значение по умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `BOT_TOKEN` | **Да** | — | Токен Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `ENV` | Нет | `dev` | Окружение: `dev` (SQLite/In-Memory) или `prod` (PostgreSQL/Redis) |
| `DATABASE_URL` | Нет | `sqlite+aiosqlite:///jobscout.db` | URL БД (`postgresql+asyncpg://...` в проде) |
| `REDIS_URL` | Нет | `None` | URL Redis (`redis://redis:6379/0` в проде) |
| `BOT_USE_WEBHOOK` | Нет | `False` | `True` для режима Webhook, `False` для Polling |
| `WEBHOOK_URL` | Нет | `""` | Публичный HTTPS URL для входящих вебхуков |
| `HEALTH_PORT` | Нет | `8080` | Порт HTTP-сервера для `/healthz` и `/metrics` |
| `SUPERJOB_API_KEY` | Рекомендуется | `""` | API-ключ с [api.superjob.ru](https://api.superjob.ru/) |
| `SENTRY_DSN` | Нет | `""` | DSN для отправки ошибок в Sentry |
| `LLM_PROVIDER` | Нет | `none` | Провайдер LLM: `none`, `openai`, `yandex`, `gigachat` |
| `DIGEST_INTERVAL_HOURS` | Нет | `6` | Интервал сводного дайджеста вакансий |

## 🚀 Быстрый запуск

### Вариант 1. Локальный запуск разработчика (`ENV=dev`)
Работает без внешних зависимостей (на SQLite с WAL-режимом):
```bash
# 1. Активация окружения и установка пакетов
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Настройка конфигурации
cp .env.example .env
# Заполните BOT_TOKEN в .env

# 3. Применение миграций схемы
alembic upgrade head

# 4. Прогон тестов (181 тест)
pytest -v

# 5. Запуск бота
python main.py
```

### Вариант 2. Развёртывание в продакшн (`ENV=prod` через Docker Compose)
Полный стек из 7 сервисов:
```bash
# 1. Запуск стека
docker compose up -d --build

# 2. Применение миграций
docker compose run --rm bot alembic upgrade head

# 3. Проверка статуса и логов
docker compose ps
docker compose logs -f bot

# 4. Проверка здоровья
curl http://localhost:8080/healthz
```

## 📱 Команды бота

- `/start` — Первичный онбординг, загрузка резюме или ручной ввод профиля.
- `/search` — Поиск вакансий по локальной базе и внешним агрегаторам.
- `/tracker` — Карьерный канбан-трекер откликов со статусами и аналитикой.
- `/favorites` — Избранные вакансии и сохранённые предложения.
- `/settings` — Фильтры по городам, удалёнке, зарплате и выбор источников (9 площадок).
- `/premium` — Тарифные планы и оплата через Telegram Stars.
- `/delete_me` — Полное удаление персональных данных и профиля (152-ФЗ / GDPR).

## 🧪 Тестирование и качество

В проекте реализовано **181 автоматических тестов `pytest`** (100% pass):
```bash
# Запуск полного сьюта тестов
pytest -v

# Оценка качества ранжирования на Golden Dataset (20 эталонных профилей)
python scripts/eval_matcher.py

# Канареечная проверка работоспособности парсеров
python scripts/canary.py
```

Состав тестового набора:
1. `test_aggregator_contracts.py` — проверка контрактов ответа всех 9 агрегаторов по сохранённым снепшотам.
2. `test_crawler_ingestion.py` — проверка фоновой ингестии, нормализации и сохранения корзин.
3. `test_deduplication.py` — 64-битный SimHash, хэммингово расстояние, кросс-платформенная дедупликация.
4. `test_ai_parsing.py` — гибридный парсинг резюме, защита от prompt injection, форматы дат.
5. `test_matcher_quality.py` — точность взвешенного ранжирования, штрафы грейдов, свежесть вакансий.
6. `test_monetization_and_tracker.py` — подписки Telegram Stars, entitlements, канбан-трекер откликов.
7. `test_observability.py` — эндпоинты `/healthz`, `/metrics`, санитизация PII в Sentry.
8. `test_resilience.py` — TokenBucket rate limiting, Circuit Breaker ТрудВсем.
9. `test_universal_professions.py` — поддержка юристов, маркетологов, бухгалтеров, сейлзов, дизайнеров.
10. `test_prod_stability.py` — атомарный троттлинг, 152-ФЗ, сессии кэша.

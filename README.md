# 🎯 JobScout Bot — Умный Telegram-бот для поиска IT-вакансий и заказов

> **JobScout Bot** — это современный асинхронный Telegram-бот, который агрегирует вакансии и фриланс-заказы с крупнейших площадок (**HeadHunter**, **Хабр Карьера**, **Kwork**, **Работа.ру**), анализирует резюме соискателя, оценивает релевантность по стеку технологий и уровню опыта, а также **надежно фильтрует скам, сомнительные предложения и вакансии с токсичными условиями (ред-флагами)**.

---

## 🌟 Ключевые возможности

1. **Многоканальный парсинг и агрегация в реальном времени**:
   - 💼 **HeadHunter (hh.ru)**: официальное REST API с поиском по навыкам, формату работы и опыту.
   - 🚀 **Хабр Карьера (career.habr.com)**: сбор актуальных вакансий для разработчиков и инженеров.
   - ⚡ **Kwork (kwork.ru)**: парсинг биржи фриланс-проектов под стек разработчика (боты, сайты, скрипты, бэкенд).
   - 👔 **Работа.ру (rabota.ru)**: поиск по базе вакансий с валидацией зарплат и условий.
   - 🧩 **Модульная архитектура парсеров**: добавление любой новой площадки занимает 1 файл с наследованием от `BaseVacanciesParser`.

2. **Интеллектуальная обработка и строгая валидация резюме**:
   - Поддержка форматов: **PDF**, **DOCX**, **TXT** и обычный текст сообщением в чат.
   - 🛡️ **Защита от «мусорных» файлов и спама (`ResumeValidator`)**: бот проверяет структуру документа (разделы: опыт работы, навыки, образование, контакты) и отсекает кулинарные рецепты, юридические договоры, стихи, случайную абракадабру или тексты без IT-навыков.
   - ⏱️ **Высокоточный расчет стажа (Алгоритм объединения интервалов — Interval Union)**:
     - Распознает диапазоны дат (`2021 — 2024`, `сентябрь 2021 — по настоящее время`).
     - Корректно объединяет перекрывающиеся периоды параллельной занятости (например, 2020–2022 и 2021–2023 дают 3 года стажа, а не ошибочные 4).
     - Для стажеров и джуниоров без коммерческого опыта корректно выставляет **0.0 лет** и грейд `Junior` (без ложного завышения до 1 года / Middle).
   - Нормализованный каталог из **300+ IT-технологий** с синонимами (`k8s` → `Kubernetes`, `postgres` → `PostgreSQL`).
   - Возможность в любой момент **заменить резюме** или вручную скорректировать стек.

3. **Географическая фильтрация (Город соискателя)**:
   - 📍 Возможность указать свой город в профиле (Москва, Санкт-Петербург, Казань, Екатеринбург, любой другой город или «Любой»).
   - **Строгое правило совместимости**:
     - Если вакансия удаленная (`is_remote=True`) — показывается всегда, независимо от города!
     - Если вакансия офисная/гибридная (`is_remote=False`) — показывается **только в городе соискателя** (офисы из других городов, например Перми при пользователе из Москвы, строго отсеиваются).
     - Интеллектуальный нормализатор синонимов городов (`мск`, `москва`, `moscow`, `спб`, `питер`).

4. **Динамическая ротация и устранение статичности выдачи**:
   - 👁️ **Отслеживание истории показов (`UserViewed`)**: вакансии, которые пользователь уже видел, не дублируются при повторных поисках.
   - 🔄 **Ротация поисковых запросов (`Query Permutation Pool`)**: бот автоматически чередует целевую роль, ядро стека и парные комбинации технологий вместо статичного фиксированного запроса.
   - 📄 **Постраничное смещение в агрегаторах**: циклический сдвиг страниц API и скрейпинга (`page 0, 1, 2...`).
   - Кнопка **«🔄 Обновить подборку (новые вакансии)»** для моментального получения свежих предложений.
   - Кнопка **«🔄 Сбросить историю просмотров»**, если вся лента просмотрена и пользователь хочет начать заново.

5. **Система скоринга и умного сопоставления (Matching Engine)**:
   - Взвешенный расчет совместимости от 0% до 100%:
     - 🎯 **50% — Пересечение стека технологий** (Must-have vs Nice-to-have).
     - 💼 **30% — Соответствие целевой роли и домена** (например, Python Backend vs Java).
     - 📈 **20% — Совместимость по грейду и опыту** (Junior не заваливается позициями Lead).
   - Подробная аналитика в карточке: какие навыки совпали, а что требуется подтянуть.
   - Опциональный **AI-ассистент (OpenAI/LLM)**: персональные рекомендации для сопроводительного письма под каждую вакансию.

6. **Движок детекции ред-флагов и защиты от скама (Red Flag Scanner)**:
   - ⛔ **Блокировка мошенничества**: требования залога, страховых взносов, платного обучения перед выходом, дропперство, обнал, сомнительные финансовые схемы.
   - ⚠️ **Предупреждения о токсичных условиях**: серая зарплата в конвертах, неоплачиваемый испытательный срок, ненормированный график 24/7 без компенсации, штрафы, подозрительный перевод общения в сторонние каналы.

7. **Эргономичный UI/UX в Telegram**:
   - Информативные карточки с цветными бейджами совпадения (`🟢 88%`, `🟡 65%`), форматом (`🏠 Удаленка` или `🏢 Офис (📍 Москва)`).
   - Интерактивная пагинация (`⬅️ Назад` / `Вперед ➡️`).
   - Кнопки быстрого перехода на вакансию (`🔗 Открыть`), добавления в избранное (`⭐`), скрытия неинтересного (`🚫`) и обновления подборки (`🔄`).
   - Фоновый мониторинг: бот проверяет новые вакансии каждые 30 минут и присылает пуш-уведомление при нахождении топового матча.

## 🛠️ Что вам нужно подготовить перед запуском (API-ключи)

Чтобы бот заработал, вам необходимо настроить переменные окружения в файле `.env`:

| Переменная | Обязательность | Описание | Где получить |
| :--- | :---: | :--- | :--- |
| `BOT_TOKEN` | **ОБЯЗАТЕЛЬНО** | Токен вашего Telegram-бота | Создайте бота у официального бота [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`) |
| `DATABASE_URL` | *Опционально* | URL подключения к БД | По умолчанию создается быстрая локальная база SQLite (`sqlite+aiosqlite:///./job_hunter.db`). Для PostgreSQL укажите `postgresql+asyncpg://user:pass@host:5432/db` |
| `OPENAI_API_KEY` | *Опционально* | Ключ OpenAI API | [platform.openai.com](https://platform.openai.com/) — нужен только для продвинутых AI-советов. **Если ключа нет, бот на 100% полноценно работает на встроенном движке!** |
| `ADMIN_IDS` | *Опционально* | ID администратора Telegram | Узнать свой ID можно у бота [@userinfobot](https://t.me/userinfobot) |

## 🚀 Быстрый запуск

### Вариант 1. Запуск через Docker Compose (Рекомендуемый для сервера)

1. Клонируйте проект или скопируйте файлы:
   ```bash
   git clone <repo_url>
   cd job-hunter-bot
   ```

2. Создайте файл `.env` из шаблона и внесите токен вашего бота:
   ```bash
   cp .env.example .env
   # Отредактируйте .env и укажите ваш BOT_TOKEN
   ```

3. Запустите контейнер:
   ```bash
   docker-compose up -d --build
   ```

4. Просмотр логов:
   ```bash
   docker-compose logs -f
   ```

---

### Вариант 2. Локальный запуск (Python 3.11+)

1. Создайте виртуальное окружение:
   ```bash
   # Linux / macOS
   python3 -m venv .venv
   source .venv/bin/activate

   # Windows
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Скопируйте и настройте `.env`:
   ```bash
   cp .env.example .env
   # Вставьте ваш BOT_TOKEN
   ```

4. Запустите тесты для проверки корректности модулей:
   ```bash
   pytest -v
   ```

5. Запустите бота:
   ```bash
   python main.py
   ```

## 📱 Как пользоваться ботом

1. **Первый запуск**:
   - Нажмите `/start`.
   - Бот поприветствует вас и предложит прислать резюме.
   - Отправьте файл резюме (PDF/DOCX) или вставьте текст в чат.
2. **Подтверждение стека**:
   - Бот покажет распознанные навыки, грейд и целевую должность.
   - Вы можете нажать «Все верно, сохранить» либо отредактировать стек / грейд.
3. **Поиск вакансий**:
   - Нажмите кнопку меню **«🔍 Найти вакансии»**.
   - Бот опросит HeadHunter, Хабр Карьеру, Kwork и Работа.ру, проведет скоринг и покажет лучшие варианты с кнопками перехода и добавления в избранное.
4. **Управление профилем и фильтрами**:
   - Меню **«👤 Мой профиль и резюме»**: замена резюме, просмотр текущего стека.
   - Меню **«⚙️ Настройки и фильтры»**: включение/выключение удаленки, фильтр по минимальной зарплате, отключение фриланс заказов, управление автопоиском.
   - Меню **«⭐ Избранное»**: просмотр всех сохраненных предложений.

## 🛡️ Безопасность и фильтрация Red-Flags

Алгоритм безопасности проверяет каждую вакансию по двум уровням:
1. **Critical Scams (Статус: BLOCKED)**:
   - Скрываются автоматически. Включают: залоги за материалы, предоплату за трудоустройство, платные курсы как условие найма, мошеннические схемы с набором текста, дропперство и финансовый обнал.
2. **Warnings (Статус: WARNING)**:
   - Помечаются предупреждающим блоком в карточке вакансии: неоплачиваемый испытательный срок, серая зарплата в конверте, требование работы 24/7 без доплат, штрафы, анонимные наниматели с переходом в сомнительные внешние чаты.

## 🧪 Тестирование

Проект покрыт 73 независимыми автоматическими тестами `pytest`:
```bash
pytest -v
```
Тесты проверяют:
- **Валидацию резюме и анти-спам** (`test_qa_suite.py`, `test_features.py`): отклонение кулинарных рецептов, договоров аренды, бессмысленного текста, коротких сообщений, не-IT текстов.
- **Точность расчета стажа** (`test_extractor.py`, `test_qa_suite.py`): 0.0 лет для стажеров/джунов, периоды по н.в. (с учетом 2026 г.), составные фразы ("3 года 8 месяцев"), алгоритм Interval Union для параллельных работ.
- **Фильтрацию по городу** (`test_qa_suite.py`, `test_features.py`): пропуск удаленки из любых городов, блокировка офисов чужих городов, нормализация синонимов ("мск" = "Москва", "спб" = "Санкт-Петербург").
- **Динамическую ротацию** (`test_qa_suite.py`, `test_features.py`): исключение просмотренных вакансий (`UserViewed`), ротация пула запросов, сброс истории.
- **Детекцию скама и ред-флагов** (`test_red_flags.py`): блокировка залогов, дропперства, обнала.
- **Взвешенный матчинг вакансий** (`test_matcher.py`): скоринг по стеку, роли и грейду.
- **Парсинг агрегаторов** (`test_parsers.py`): извлечение и валидация зарплат, бюджетов и данных вакансий.

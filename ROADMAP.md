# 🗺️ Дорожная карта проекта (Roadmap) — JobScout Bot

План развития и масштабирования Telegram-бота для агрегации IT-вакансий и карьерного сопровождения.

---

## 🚀 Версия 1.0 – 1.1 (Текущая версия — Выполнено ✅)

- [x] **Многоканальный сбор данных (9 интегрированных платформ)**:
  - [x] Интеграция с официальным REST API HeadHunter (hh.ru) с многостраничной выгрузкой.
  - [x] Скрейпинг профильных IT-вакансий Хабр Карьеры (career.habr.com).
  - [x] Официальное открытое REST API госслужбы «Работа России» (trudvsem.ru, 25 000+ вакансий).
  - [x] Интеграция с SuperJob (superjob.ru) с поддержкой REST API v2 и веб-поиска.
  - [x] Открытое REST API мирового портала удаленки RemoteOK (remoteok.com) с зарплатами в USD.
  - [x] Парсинг заказов маркетплейса Kwork (kwork.ru).
  - [x] Парсинг RSS-лент крупнейшей биржи фриланса FL.ru (fl.ru) по программированию и сайтам.
  - [x] Парсинг RSS-ленты IT-проектов Хабр Фриланс (freelance.habr.com).
  - [x] Скрейпинг вакансий экосистемы Сбера Работа.ру (rabota.ru).
- [x] **Максимальная гибкость выдачи и снятие ограничений**:
  - [x] Мульти-запросный параллельный сбор (`asyncio.gather` по 3–5 разнообразным запросам).
  - [x] Пул запросов: английские названия ролей, русские синонимы, ключевой язык, фреймворки, инфраструктура.
  - [x] Многостраничный сбор (`scan_pages=2` для основных агрегаторов).
  - [x] Расширение локальной выборки БД до 500 вакансий (вместо жесткого лимита 100).
  - [x] Адаптивный скоринг (мягкий порог 35% с бейджем «Зона роста», если строгих матчей мало).
- [x] **Динамическая ротация и устранение повторов**:
  - [x] Отслеживание просмотренных вакансий (`UserViewed` в БД) и их исключение из ленты.
  - [x] Кнопка «🔄 Обновить подборку (новые вакансии)» с циклическим смещением запросов и страниц.
  - [x] Кнопка «🔄 Сбросить историю просмотров» при завершении ленты.
- [x] **Географическая фильтрация (Город соискателя)**:
  - [x] Нормализатор городов (`CityNormalizer`) с каталогом синонимов (Москва/мск, Санкт-Петербург/спб, Казань, Пермь и др.).
  - [x] Строгое правило: удаленка доступна всем, офисы чужих городов (например, Перми при соискателе из Москвы) строго блокируются.
  - [x] Инлайн-выбор города соискателя в меню настроек `/settings`.
- [x] **Обработка, валидация резюме и расчет стажа**:
  - [x] Поддержка файлов PDF, DOCX, TXT и текстового ввода в чат.
  - [x] Валидатор резюме (`ResumeValidator`): блокировка рецептов, договоров, литературных текстов и абракадабры.
  - [x] Высокоточный расчет стажа (Алгоритм Interval Union): корректное объединение параллельных работ.
  - [x] Корректный расчет нулевого опыта (0.0 лет и Junior для стажеров без опыта).
  - [x] Поддержка периодов по н.в. (с учетом текущего 2026 г.) и составных фраз («3 года 8 месяцев»).
  - [x] Каталог из 300+ IT-технологий с нормализацией синонимов (`k8s` → `Kubernetes`, `postgres` → `PostgreSQL`).
- [x] **Детекция мошенничества и Red-Flags**:
  - [x] Автоматическая блокировка скама (залоги, страховые взносы, дропперство, наборы текста).
  - [x] Выявление токсичных условий (серая ЗП, неоплачиваемый испытательный срок, режим 24/7).
- [x] **Универсальная поддержка всех профессий и отраслей**:
  - [x] Снятие ограничений только на IT: поддержка маркетинга, дизайна, продаж, бухгалтерии, финансов, HR, юриспруденции, логистики и менеджмента.
  - [x] Расширенная база профессиональных навыков (450+ скиллов) с нормализацией и извлечением списков из резюме.
  - [x] Умный парсер ролей и предметный генератор запросов к агрегаторам без навязывания IT-терминов.
  - [x] Универсальный скоринг и адаптивный подбор вакансий и фриланс-задач для любых направлений.
- [x] **Продакшн-стабильность, безопасность и комплаенс**:
  - [x] Защита от спама и флуда: `ThrottlingMiddleware` с мягким rate-limiting и всплывающими alert-сообщениями.
  - [x] Устранение утечек памяти: `SearchResultsCache` со строгим лимитом размера и автоматической TTL-очисткой.
  - [x] Соответствие 152-ФЗ и GDPR: команда `/delete_me` и кнопка в настройках для полного удаления всех данных пользователя.
  - [x] Защита фонового планировщика: безопасный перехват `TelegramForbiddenError` с деактивацией заблокировавших бота пользователей.
  - [x] Connection Pooling для PostgreSQL (`pool_size=20`, `pool_pre_ping=True`) и потокобезопасность SQLite.
  - [x] Отказоустойчивость API ТрудВсем: ограничение пагинации, приоритет HTTP над медленным HTTPS и автовосстановление при 500.
- [x] **Инфраструктура и качество**:
  - [x] Полное покрытие тестами: **130 автоматических тестов pytest (100% pass)**.
  - [x] Docker и Docker Compose с volume-монтированием базы данных.
  - [x] Полная документация проекта (README, PROJECT_STRUCTURE, ROADMAP).

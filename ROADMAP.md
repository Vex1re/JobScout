# 🗺️ Дорожная карта проекта (Roadmap) — JobScout Bot

План развития и масштабирования Telegram-бота для агрегации вакансий и карьерного сопровождения соискателей всех специальностей.

---

## 🚀 Версии 1.0 – 1.5 (Реализовано ✅)

### 1. Фундамент и отказоустойчивость
- [x] **Архитектура очередей задач и воркеров**:
  - [x] Внедрение распределённой асинхронной очереди `arq` поверх Redis.
  - [x] Изолированные воркеры `worker-crawler` (сбор вакансий) и `worker-notifier` (отправка сообщений).
  - [x] Выделенный сервис планировщика `scheduler` (singleton APScheduler).
- [x] **Уровень хранения данных**:
  - [x] Поддержка PostgreSQL 16 с connection pooler **PgBouncer** (transaction pooling).
  - [x] Локальный dev-режим на SQLite с `PRAGMA journal_mode=WAL` и увеличенным `busy_timeout`.
  - [x] Полное версионирование схемы БД через **Alembic** (отказ от `create_all` в проде).
- [x] **Кэширование и FSM**:
  - [x] Хранение FSM-состояний в Redis (`RedisStorage`) с плавным fallback на In-Memory в dev.
  - [x] Атомарный `ThrottlingMiddleware` на Lua-скриптах в Redis с локальным fallback.
  - [x] Двухуровневый `SearchResultsCache` со строгим TTL и контролем размера.

### 2. Ingestion Pipeline и Дедупликация
- [x] **Разделение сбора и поиска**:
  - [x] Фоновый сбор корзин (профессия × город × remote) независимо от действий пользователей.
  - [x] Индексированная таблица `vacancies` с полями нормализации, грейда, опыта и ред-флагов.
- [x] **Дедупликация**:
  - [x] Детерминированный `canonical_id` (хэш компании, названия, города и зарплаты).
  - [x] **SimHash (64-битный отпечаток)** описания вакансий (Hamming distance $\le 3$) для схлопывания дублей между разными источниками.
- [x] **Защита внешних платформ**:
  - [x] TokenBucket rate limiter для каждого агрегатора.
  - [x] CircuitBreaker с защитой от каскадных сбоев и 500-ошибок (ТрудВсем).

### 3. Парсинг, Агрегация и Универсальные профессии
- [x] **9+ платформ сбора данных**:
  - [x] HeadHunter (официальное REST API, многостраничный опрос).
  - [x] Хабр Карьера (профильные IT-вакансии).
  - [x] Работа России / ТрудВсем (открытое REST API без капч).
  - [x] SuperJob (REST API v2 + веб-поиск).
  - [x] RemoteOK (мировое API удалёнки в USD).
  - [x] Kwork (микроуслуги и проектные задачи).
  - [x] FL.ru (крупнейшая биржа фриланса).
  - [x] Хабр Фриланс и Freelance.ru.
  - [x] Работа.ру (с поддержкой прокси).
  - [x] Freelancehunt API v2 (под feature-флагом).
- [x] **Универсальные профессии (не только IT)**:
  - [x] Снятие ограничений: маркетинг, продажи, бухгалтерия, дизайн, HR, юриспруденция, логистика.
  - [x] Каталог навыков: 192 канонических скилла и 250+ синонимов.
  - [x] Каталог 165 городов РФ (`data/cities.json`) с учётом региональных центров.

### 4. Анализ резюме и Ранжирование
- [x] **Гибридный парсинг**:
  - [x] Высокоскоростной regex/эвристический расчёт стажа (Interval Union) и навыков.
  - [x] Опциональный LLM fallback (OpenAI, YandexGPT, GigaChat) с согласия пользователя (`llm_consent=True`).
  - [x] Санитизация Prompt Injection и маскирование PII (телефоны, email).
- [x] **Матчинг и ранжирование**:
  - [x] Конфигурируемые веса (45% стек, 25% роль, 30% опыт/грейд).
  - [x] Soft grade penalty (штраф 12% при низкой уверенности вместо отсечения).
  - [x] Freshness time decay (плавное снижение скора для старых вакансий).
  - [x] Оценка качества на Golden Dataset (20 эталонных профилей со 100% метриками Recall@10 и Precision@5).

### 5. Монетизация и Карьерный трекер
- [x] **Оплата через Telegram Stars (XTR)**:
  - [x] Команда `/premium`, тарифы PRO (150 Stars) и TEAM (400 Stars).
  - [x] Обработка `PreCheckoutQuery` и `SuccessfulPayment`.
  - [x] Архитектура Entitlements (гранулярные права доступа).
  - [x] Альтернативные шлюзы (ЮKassa, CryptoBot) за feature-флагами.
- [x] **Канбан-трекер откликов**:
  - [x] Команда `/tracker`: статусы откликов (`Сохранено`, `Откликнулся`, `Интервью`, `Оффер`, `Отказ`).
  - [x] Добавление вакансии в трекер в 1 клик прямо из карточки.
  - [x] Персонализированный генератор **AI Cover Letters**.
  - [x] **AI Gap Analysis** (анализ недостающих навыков соискателя).

### 6. Observability и Безопасность
- [x] **Метрики и мониторинг**:
  - [x] Эндпоинт `/healthz` (Liveness/Readiness пробы БД и Redis).
  - [x] Эндпоинт `/metrics` (Prometheus метрики: сбор, ошибки, латентность, пользователи).
  - [x] Sentry интеграция с PII Redaction.
  - [x] Канареечные тесты парсеров (`scripts/canary.py`).
  - [x] Контрактные тесты 9 агрегаторов (`tests/test_aggregator_contracts.py`).
- [x] **Безопасность и комплаенс**:
  - [x] Полное удаление данных по 152-ФЗ / GDPR (`/delete_me`).
  - [x] Telegram Rate Limiter (TokenBucket 25 msg/s) для защиты от 429.
  - [x] Консолидация одиночных уведомлений в периодические дайджесты.
- [x] **Тестирование**:
  - [x] **181 автоматический тест pytest (100% pass)**.
